# Influencer On The Run - Game Premise

## Core Concept
"Influencer On The Run" is a satirical endless runner game that explores the extremes of social media culture. Players control a rising social media star who has turned a chaotic situation into a viral livestream opportunity, using the attention-grabbing strategy of "less clothes, more views" to maximize engagement.

## Main Storyline
Set in a neon-lit, chaotic cityscape, the game follows an influencer who has transformed an embarrassing situation into a viral livestream. Rather than hiding from the chaos, she's embracing it for content, running through the streets while streaming her adventures to gain more views and followers.

## Gameplay Context
- Players control the influencer character in a continuous forward run
- The primary objective is to maximize views while surviving as long as possible
- The game features various obstacles that represent different aspects of social media fame:
  - Paparazzi attempting to capture compromising photos
  - Overzealous fans and creeps trying to get too close
  - Random urban chaos elements
  - Social media trolls and haters
- Collectible rewards boost view counts and provide temporary advantages

## Key Themes
1. **Social Media Culture**: Satirizes the extreme measures content creators take for fame and engagement
2. **Content Creation**: Explores the transformation of personal situations into public entertainment
3. **Survival**: Combines physical survival (avoiding obstacles) with digital success (gaining views)

## Visual Style
- Vibrant, modern city environment with neon aesthetics
- Character design that contrasts glamorous influencer style with chaotic surroundings
- UI elements that mimic social media metrics and engagement indicators
- Dynamic lighting and effects that emphasize the livestream aesthetic

## Game Mechanics
- Endless runner format with progressively increasing difficulty
- View counter as the primary scoring system
- Collectible rewards that provide:
  - View count multipliers
  - Temporary power-ups
  - Special effects for the livestream
- Obstacle avoidance and timing-based gameplay
- Combo system for consecutive successful maneuvers

## Target Audience
- Social media-savvy players who understand influencer culture
- Casual gamers who enjoy endless runners
- Players who appreciate satirical humor and social commentary
- Content creators who can relate to the gameplay themes

## Development Notes
- The game is built publicly and welcomes community contributions
- Version 1.0 focuses on core gameplay mechanics
- Future updates can expand:
  - Additional character customization options
  - New obstacle types
  - Special events and challenges
  - Social media platform integration features

## Technical Context
- HTML5 Canvas-based game
- Responsive design for various screen sizes
- Modular JavaScript architecture for easy expansion
- Optimized for smooth performance on mobile and desktop platforms
